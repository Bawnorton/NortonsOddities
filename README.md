# Spore Additions

Adds QOL features to the Spore mod

## Features
- Adds `sporeaddtions freeze/unfreeze/is_frozen` command
- Adds JEI recipe insertion support for the surgery table


When spore is frozen all its entities will no longer tick, the blocks will still behave as normal and you can still get effects from interacting with them but the main spreading mechanic and onslaughts will be completely halted.
